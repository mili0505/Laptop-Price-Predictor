## Laptop Price Predictor

A Machine Learning based web application that predicts the price of a laptop based on its specifications.


## Project Overview

The Laptop Price Predictor takes laptop specifications such as brand, RAM, processor, storage, display size, GPU and laptop type as input and predicts the estimated laptop price.

The application is developed using Python, Machine Learning and Streamlit.


## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook


## Features
- Interactive web interface
- Laptop price prediction
- Multiple laptop specifications as input
- Machine Learning based prediction
- Easy-to-use Streamlit application


## Input Features

The application uses features such as:
- Brand
- RAM
- RAM Type
- RAM Expandability
- Processor Speed
- Processor Family
- GPU Brand
- GPU Type
- SSD Storage
- Display Size
- Laptop Type
